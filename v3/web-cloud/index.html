How to add to OBS Studio / Streamlabs:

  1. In OBS Studio, click + under Sources and select Browser.
  2. Name it Fortnite Chest Tracker and click OK.
  3. Paste the copied URL into the URL field.
  4. Set Width to 300 and Height to 100.
  5. Click OK. The transparent counter will automatically display and update live on stream!

Browser Folder Access Notice

Google Chrome and Microsoft Edge security policies prevent web pages from directly opening folders inside AppData ("contains system files").

Option 1: Select C:\FortniteReplays
Select This PC > Local Disk (C:) > FortniteReplays. Chrome opens this folder with zero warnings and auto-updates live!
Option 2: Select .replay Files Directly
Browsers allow selecting individual replay files directly from AppData with zero warnings.
