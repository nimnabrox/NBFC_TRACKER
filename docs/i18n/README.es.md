## ¿Listo para descubrir más?

1. **Activa las repeticiones.** En Fortnite: Ajustes → Juego → Repeticiones → Grabar repeticiones → Sí.
2. **Abre la aplicación.** Ejecuta NBFC TRACKER en Windows. Lee tus repeticiones y mantiene los perfiles separados.
3. **Llévalo a tu emisión.** Pega la URL del overlay en una fuente de navegador de OBS. Mantén la aplicación abierta.

## Ajustes

- **Cantidad inicial de cofres:** Establece tu total actual para este perfil. Los cofres nuevos se suman automáticamente. Bórralo para usar las repeticiones.
- **Carpeta de repeticiones:** Requiere la aplicación de Windows. Usa la carpeta predeterminada salvo que las repeticiones estén en otra ubicación.
- **Sala en la nube:** Introduce la sala de la URL del overlay de tu aplicación para verla en otro dispositivo. Los enlaces son públicos.
- **Idioma:** Bahasa Indonesia, Deutsch, English, Español, Español (Latinoamérica), Français, Italiano, Polski, Português (Brasil), Tiếng Việt, Türkçe, Русский, العربية, ไทย, 日本語, 简体中文, 繁體中文, 한국어.

## Overlay de emisión

Añade el contador como fuente de navegador en OBS. Tamaño: 420 × 120.

~~~text
https://nbfct.nimnabro.com/overlay?room=YOUR_ROOM&lang=es
~~~

Lee repeticiones locales. No accede a la memoria del juego. Sin afiliación con Epic Games.
